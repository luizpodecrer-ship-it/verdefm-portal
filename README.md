# Verde FM · Portal de notícias (front-end)

Front-end do novo portal da Rádio Verde FM: HTML, CSS e JavaScript puros, prontos para virar tema WordPress.

- `site/` — o site (é o que o Netlify publica)
- `docs/WORDPRESS.md` — guia para o desenvolvedor do WordPress
- `ferramentas/` — só para a demonstração: coleta matérias dos sites atuais (`coletar-demo.py`) e gera as páginas internas a partir da home (`gerar-demo.py`)
- `CLAUDE.md` — regras do projeto e decisões aprovadas

Para ver no computador: sirva a pasta `site/` por HTTP (ex.: `python3 -m http.server` dentro de `site/`) e abra `http://localhost:8000`.
